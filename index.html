🧰 Toolsruns in your browser

Free, private, offline developer tools

tools.vanshul.com is a collection of 23 everyday developer utilities plus a Smart Paste box that auto-detects whatever you drop in. Every conversion runs entirely in your browser using plain JavaScript and the Web Crypto API — nothing is ever uploaded to a server, there are no accounts or ads, and the whole app works offline as an installable PWA.

Every tool included

  • JSON formatter — pretty-print, minify & validate JSON.
  • Base converter — convert between binary, octal, decimal, hex & base 36.
  • Base64 — encode & decode Base64 (UTF-8 safe).
  • URL encode — encode / decode URL components & query strings.
  • JWT decoder — inspect a JSON Web Token's header, payload & claims.
  • Hash — SHA-1, SHA-256 & SHA-512 of any text.
  • ID & random — UUID v4/v7, ULID, nanoid, hex & passwords.
  • Timestamp — convert between Unix time and dates.
  • Color — convert HEX, RGB & HSL with a picker.
  • Text — word / character counts & case conversion.
  • Line diff — compare two blocks of text line-by-line.
  • Regex tester — live matches, capture groups & replace preview.
  • Token & cost — approximate LLM token count & input cost.
  • Cron — explain a cron expression & preview the next runs.
  • JSON ⇄ YAML — convert between JSON and YAML.
  • JSON tools — JSON → TypeScript types, sort keys & path query.
  • Markdown preview — render Markdown into clean HTML in-browser.
  • Image → data URI — turn a local image into a data URI or CSS background.
  • cURL → code — turn a curl command into fetch or Python requests.
  • Transform — sort / dedupe lines, slugify, case styles, CSV ⇄ JSON.
  • HMAC & CRC — keyed HMAC-SHA and CRC32 checksums.
  • QR code — generate a scannable QR code, fully offline.
  • QR reader — read a QR code from a local image, without uploading it.
  • Smart Paste — paste a JWT, JSON, Base64, colour, timestamp or UUID and it auto-detects & decodes it.

Frequently asked questions

Is my data uploaded anywhere?
No. Every conversion runs entirely in your browser with plain JavaScript and the Web Crypto API. There are no server round-trips for any tool and no analytics that read your input.
Does it work offline?
Yes. The app is an installable PWA with a service worker, so after your first visit every tool keeps working with no internet connection.
Is it free?
Yes, it is completely free with no accounts, no sign-up and no ads that read your data.
Does the JWT decoder verify signatures?
No. The JWT tool only decodes and inspects the header, payload and claims — it does not verify the signature, so never trust a token based on this tool alone.
Are the QR codes generated on my device?
Yes. QR codes are encoded entirely in your browser (byte mode, error-correction level M) — nothing is sent to a server.
